# Chess club elo calculator
This script is designed to register chess club members, calculate elo and record changes

# Motivation
I built this project to improve the chess club experience at my school and give myself a challenging beginner python project

# Tech Stack
Language: Python 3.14
Core modules used: `re` (Regular Expressions)
Programming concepts: File Management, Automated Data String Replacement

# Reflection
Learned how to manipulate file data using python
Learned how to build a system for practical use using simple coding logic
